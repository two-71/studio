# Contributing

Thanks for your interest in contributing to `@two-71/studio`.

This project is early and evolving quickly; detailed contribution guidelines (issue triage, PR process, coding conventions) will be fleshed out here as the project stabilizes. In the meantime:

- Use `bun` for all package management (`bun install`, never `npm`/`yarn`).
- Run `bun run typecheck` and `bun run check` before opening a PR.
- Keep changes scoped and focused; explain the "why" in your PR description.
- Open an issue to discuss non-trivial changes before starting work.

By contributing, you agree your contributions will be licensed under this project's MIT license.
